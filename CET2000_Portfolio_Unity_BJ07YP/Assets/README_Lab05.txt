CET2000 – Lab 05 Starter Pack: Finite State Machines (Unity 6.5)
=================================================================

Quick start
1. Unity Hub -> Add -> Add project from disk -> this folder. Open with Unity 6.5 (any Unity 6 works).
2. Click "Create scene" in the CET2000 dialog, or use CET2000 -> Create Lab05 FSM Scene.
3. Open Assets/Scripts/GuardFSM_Template.cs and complete TODO 1 to 6.

Scripts
  GuardFSM_Template.cs  the guard FSM - YOU complete the TODOs (helpers are provided)
  GuardStates.cs        Expert E3: the same FSM as one class per state (complete Chase, Attack, Flee)
  PlayerController.cs   the player (provided): WASD / arrows, Space to hit the guard, autopilot
  FSMHud.cs             on-screen panel (provided): state, health, last state changes, test buttons

Documentation
  Lab05_Instructions.md     short version of the handout
  FSM_Design_Worksheet.md   diagram, Enter/Exit actions, design questions, test table
